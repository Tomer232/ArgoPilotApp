## What we built

- **registry-service (8000):** moved from raw SQLite to SQLAlchemy Core; runs on PostgreSQL (`registry`) or SQLite with only `DATABASE_URL` changed (NFR-2.1). `/docs` is back on (Y13).
- **weather-service (8001):** daily ET0 and rain from Open-Meteo, cached in memory per 0.1° cell; a stale answer (`"stale": true`) when the provider fails, up to 24 h old.
- **planner-service (8002):** the 7-day irrigation plan per plot from FAO-56 (Kc by stage, growing roots, soil bucket, rain, 24-hour cap, litres and drip minutes). It calls only registry and weather (`upstream.py`).
- **frontend (3000):** Next.js 16 + Tailwind 4 + shadcn/ui. Plot list and plot page with today's answer, the 7-day plan, a timeline and a Table/Chart switch. Only the Next.js server calls the services.
- **Project skills:** `irrigation-calc-reference`, `run-stack`, `qa`, `test`, `requirements`, `submit-task`.
